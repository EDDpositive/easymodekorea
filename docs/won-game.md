# 서울에서 얼마? 하루 한 판 가격 맞히기: 4주 시험

- 화면: `won/`(영어), `won/ja/`, `won/zh-tw/`, `won/zh-cn/`, `won/vi/`. 사이트 메뉴와 앱에는 안 나오고 사이트맵에만 있음. 오프라인 저장도 따로(`won/sw.js`, 캐시 이름 `won-`).
- 만드는 곳: `src/won.py`(화면·점수), `src/won_data.py`(값 118개와 출처 29곳), `src/won_text.py`(5개 언어 글), `src/won_art.py`(그림 53개, 모두 직접 그림). 아이콘·미리보기 그림은 `tools/make_won_assets.py`.
- 하루 5문제: 교통, 음식, 나들이·생활, 시장, 그리고 여러 값을 더하는 계산. 돈을 눌러 쟁반에 놓고 "Pay". 점수는 작은 쪽 ÷ 큰 쪽(₩10,000짜리에 ₩5,000도 ₩20,000도 50점), 무료는 ₩25마다 1점 빠짐. 다섯 점수의 평균이 그날 점수.
- 날짜가 같으면 누구나 같은 문제(폰 시계 자정에 바뀜). 1번 날은 `START`(2026-11-26). 지난 날은 결과 아래에서 다시 할 수 있음.
- 하지 않는 것: 소리, 광고, 가입, 입력값 전송, 결제업계·제휴 내용, 다른 게임 이름. `tools/check_site.py`가 찾으면 실패함.

## 값 규칙
1. 공식 페이지가 숫자를 적은 것만. 없으면 그 문제를 뺌(KTX, 공항철도, 보관함, 시티투어버스, 고기 등은 뺐음).
2. 값마다 출처 주소와 날짜. 조사 평균(price.go.kr, KAMIS)은 "서울 평균, 몇 월", 정해진 값은 "몇 월 며칠 기준"으로 보임.
3. 환율 한 줄(₩10,000이 얼마인지)은 관세청 주간 환율(`FX`). 베트남어 화면은 그 표에 동이 없어 달러로 보여 줌.

### 값을 써도 되는지 (2026-11-26에 읽음)
| 값 | 이용 조건 |
|---|---|
| KAMIS 시장 값 48개 | 공공데이터포털에 "이용허락범위 제한 없음"으로 열려 있음([15156062](https://www.data.go.kr/data/15156062/openapi.do)) |
| price.go.kr 외식·서비스·공공요금 17개 | 행정안전부 자료라고 적혀 있고 "잠정치"임. 자유 이용 표시(공공누리)는 못 찾음 → **확인 안 됨**. 낱개 숫자만 출처·링크·날짜와 함께 적고, 표나 글은 옮기지 않음 |
| 요금·입장료·최저임금·우편·환율 | 기관이 공고한 값. 출처와 날짜를 적음 |

### 주마다 (2분)
`python tools/won_price_check.py`: 공식 페이지 20곳을 다시 읽어 값이 사라진 문제를 보여 줌. 나온 것만 고치고 `SRC`의 날짜를 바꿈.

### 달마다 (시험을 통과한 뒤부터)
- price.go.kr(외식·서비스·공공요금)과 KAMIS(시장) 값을 새 달 값으로. `FX`도 같이.
- 2027-01-02: 교통요금, 우편요금, 입장료를 다시 확인.

### 문제를 더하거나 뺄 때
- `ORDER` 줄의 순서가 곧 날짜입니다. 새 문제는 줄 끝에 붙입니다. 한 바퀴(28일)를 돈 뒤에는 줄 길이가 바뀌면 지난 날 문제가 달라지므로, 그때는 시작일별 목록을 나누는 작업을 먼저 합니다.
- 같은 날 이미 물은 값이 다섯 번째 계산에 또 나오지 않게 `SCENES` 순서를 맞춰 둠(365일 검사).

## 방문 수를 재는 방법 (공개 전에 정함)
- **잴 것: 한 주(7일) 동안 `/won/`, `/won/ja/`, `/won/zh-tw/`, `/won/zh-cn/`, `/won/vi/` 다섯 주소의 방문 합계.** 이미 사이트에 있는 GoatCounter만 씀. 새 도구·계정 없음.
- 같이 볼 것(GoatCounter 이벤트 `won/<언어>/…`): `start` 첫 문제를 푼 수, `done` 다섯 문제를 다 푼 수, `share`·`pic` 나눈 수, `friend` 친구 링크로 온 수, `emk` 본 사이트로 간 수.
- 읽는 사람: GoatCounter 공개 설정(승인 14번 ②)이 켜져 있으면 Claude가 직접 봄. 꺼져 있으면 정하는 날에 기웅 님이 화면 한 장을 찍어 줌.
- 빼고 볼 것: 우리가 시험하며 연 방문. 공개 첫날 숫자는 참고만.

## 정하는 날 (공개한 날 = 0일)
| 날 | 보는 것 | 정하는 것 |
|---|---|---|
| 14일째 | 방문, 시작→끝 비율 | 끝까지 푸는 비율이 60% 아래면 문제 순서·첫 화면만 고침 |
| 28일째 | 22~28일째 한 주 방문 합계 | **100 미만이면 접음**(주소는 닫고 본 사이트로 넘김). 100~499면 2주 더 보고 끝. 500 이상이면 앱으로 감싸는 안을 올림 |

알리는 글 없이 공개만 하면 검색 말고는 들어올 길이 없어 100을 넘기 어렵습니다. 공개와 알리기는 따로 승인받습니다.
