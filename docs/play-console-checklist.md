# 플레이 콘솔 체크리스트 (기웅 님만 할 수 있는 일)

Claude는 로그인, 비밀번호 입력, 약관 동의, 업로드, 제출을 하지 않습니다. 아래는 기웅 님이 직접 하시는 순서입니다. 붙여 넣을 문구와 답은 모두 [store/listing.md](../store/listing.md)에 있습니다.

## 일정 한눈에
- 비공개 테스트 시작 → **테스터 12명 이상이 14일 연속 참여** → 정식 출시 신청 → 구글 심사(보통 며칠) → 공개.
- 그래서 정식 공개는 테스트를 시작한 날부터 빨라야 약 3주 뒤입니다.
- 테스터는 구글 계정(지메일 주소) 12개 이상이 필요합니다. 중간에 빠지면 14일을 다시 세므로 넉넉히 15명쯤 모으는 것이 안전합니다.
- 테스터에게 보낼 글, 14일 일정, 정식 출시 신청서 초안은 [closed-test-plan.md](closed-test-plan.md)에 있습니다.

## 지금 어디까지 왔나 (2026-11-23)
- 끝남: 개발자 계정 만들기(개인, 이름 "EasyModeKorea", 사업용 지메일 계정, 등록비 결제). 사이트 반영(PR #9, #11 머지). 스토어 문구·스크린샷 8장·출시 노트([store/release-notes.md](../store/release-notes.md)). 앱 파일(서명 전).
- 막힌 곳: 플레이 콘솔 홈의 세 가지가 모두 "조치 필요"라 **"앱 만들기" 버튼이 꺼져 있습니다**. 2026-11-23 크롬에서 다시 봤을 때도 "본인 확인"에 서류 올리기 창이 그대로 있었습니다.

- **2026-11-25: 앱을 설치할 이유가 있게 다시 만들었습니다**(SOS 위치번호, 음식 카드, 거절당했을 때 3번 누르기, 여행 날짜별 할 일, 앱 아이콘 바로가기 4개). 그 PR을 머지한 뒤에 앱 파일을 **다시 만들어야** 합니다. 11-23에 받아 둔 파일은 바로가기가 옛것이라 올리지 않습니다.
- **개인 계정은 건강 기능이 있는 앱을 낼 수 없습니다**([구글 안내](https://support.google.com/googleplay/android-developer/answer/13634885), 2026-11-25 확인). 그래서 병력·약·혈액형 카드는 이번 버전에서 뺐습니다. 자세한 이유는 listing.md의 "Health question".

## 1. 계정 확인 (기웅 님, 순서대로)
- [ ] **본인 확인**: 크롬에서 플레이 콘솔(사업용 지메일 계정) 홈 > "본인 확인" > 시작하기 > 여권 사진 올리기 > 제출. 고치거나 자른 사진은 반려됩니다. 승인까지 며칠 걸릴 수 있습니다.
- [ ] **안드로이드 기기 확인**: 갤럭시에서 플레이 스토어로 "Google Play Console" 앱 설치 > 같은 사업용 지메일로 로그인.
- [ ] **전화번호 인증**: 본인 확인이 승인된 뒤 홈에 열립니다. 문자로 온 번호 입력.
- [ ] 세 가지가 끝나 "앱 만들기"가 파랗게 바뀌면 Claude에게 알려 주기. 그 뒤 칸 채우기는 Claude가 하고, 동의 체크와 파일 올리기만 기웅 님이 누릅니다.
- [ ] 테스터 12~15명에게 지메일 주소 받기(지금 해도 됨). 보낼 글은 [closed-test-plan.md](closed-test-plan.md)의 "1단계".

## 2. 앱 만들기 (버튼이 켜진 뒤)
- [ ] 플레이 콘솔 > 앱 만들기. 아래 네 칸은 Claude가 채울 수 있습니다.
  - 앱 이름 `EasyModeKorea: Korea Travel`, 기본 언어 `영어(미국) – en-US`, 앱 또는 게임 `앱`, 무료 또는 유료 `무료`
- [ ] **기웅 님이 직접 체크**: 같은 화면 아래 "신고" 두 개(개발자 프로그램 정책 준수, 미국 수출법 준수). 체크한 뒤 "앱 만들기".
- [ ] 대시보드의 "앱 설정" 항목: 개인정보처리방침 주소, 앱 액세스 권한, 광고, 콘텐츠 등급, 타겟층, 데이터 보안, 정부 앱, 금융 기능, 건강. 답은 listing.md의 "App content forms" 표 그대로(Claude가 채움). 콘텐츠 등급 마지막의 "제출", 데이터 보안의 "저장", **건강의 답 고르기와 "저장"은 기웅 님이 누름**(사실을 신고하는 칸이라 Claude가 대신 정하지 않음. 추천 답과 이유는 listing.md).
- [ ] 스토어 등록정보: 영어 이름·설명은 Claude가 붙여 넣음, 한국어 번역 추가. **파일 올리기는 기웅 님**: 아이콘(`icon-512.png`), 대표 이미지(`store/feature-graphic.png`), 폰 스크린샷 8장(`store/screenshots/` 폴더, 1번부터 순서대로).
- [ ] 스토어 설정: 앱 카테고리 `여행 및 지역정보`, 이메일 `listing.md`의 문의 주소, 웹사이트 `https://easymodekorea.com`.

## 3. 앱 파일 만들기와 서명 (이 PC에서 한 번)
개발자 계정 인증을 기다리는 동안 해 둘 수 있습니다.
- [ ] 자바 설치(무료, 약 180MB). PowerShell에서 `winget install EclipseAdoptium.Temurin.17.JDK`
- [ ] (PR 머지 뒤) main 기준 앱 파일 다시 빌드: 버전 1.0.0, 코드 1. Claude가 만들어 `내 사용자 폴더\.emk-android\out\main-1.0.0\easymodekorea-unsigned.aab`에 바꿔 넣습니다. **바꿨다고 말하기 전에는 서명하지 마세요**(지금 있는 파일은 옛 바로가기).
- [ ] 새 PowerShell 창에서 실행(서명 스크립트 사본도 같은 폴더에 있습니다): `powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\.emk-android\sign-aab.ps1" -Aab "$env:USERPROFILE\.emk-android\out\main-1.0.0\easymodekorea-unsigned.aab"`
  - 처음 한 번은 **새 비밀번호를 직접 정해 두 번 입력**합니다. 이 비밀번호와 `내 사용자 폴더\.emk-android\emk-upload.jks` 파일은 꼭 따로 보관하세요. 둘 다 잃으면 구글에 재설정을 요청해야 합니다.
  - 끝나면 서명된 파일(`easymodekorea-날짜.aab`)이 있는 폴더가 열리고, "지문(SHA-256)" 한 줄이 나옵니다.

## 4. 비공개 테스트 시작
- [ ] 플레이 콘솔 > 테스트 > 비공개 테스트 > 새 버전 만들기 > 서명된 `.aab` 올리기. 출시 노트는 [store/release-notes.md](../store/release-notes.md)의 블록을 통째로 붙여 넣기.
- [ ] 테스터 목록에 지메일 주소 12개 이상 넣기 > 검토 요청 보내기.
- [ ] 플레이 콘솔 > 테스트 및 출시 > 앱 무결성 > 앱 서명에서 **"앱 서명 키 인증서"의 SHA-256 지문**을 복사해 Claude에게 전달. (공개해도 되는 값입니다. Claude가 사이트에 넣으면 앱에서 주소창이 사라집니다.)
- [ ] 검토가 끝나면 테스터들에게 참여 링크(https://play.google.com/apps/testing/com.easymodekorea.app) 보내기. 보낼 글은 closed-test-plan.md의 "2단계". 설치 후 14일 동안 지우지 않게 부탁하기.

## 5. 14일 뒤

## 폰에서 직접 확인할 것 (5분)
Claude는 실제 안드로이드 폰이 없어 PC 브라우저와 앱 파일 분석으로만 검증했습니다. 아래는 폰에서만 보이는 것들입니다. 이상하면 화면을 찍어 Claude에게 주세요.

**사이트를 홈 화면에 설치했을 때 (머지 직후 가능)**
- [ ] 크롬으로 easymodekorea.com 열기 → 가이드 두 개쯤 본 뒤 아래에 뜨는 "Install" → 홈 화면 아이콘으로 열리는지
- [ ] 열릴 때 파란 화면에 EM 표시가 잠깐 보이는지, 흰 상자가 보이지 않는지
- [ ] 비행기 모드에서 열어 가이드와 한국어 카드가 열리는지, 아래에 "오프라인" 띠가 보이는지
- [ ] 한국어 카드를 전체 화면으로 띄운 뒤 **뒤로 가기**를 누르면 카드만 닫히는지
- [ ] 아이콘을 길게 눌러 바로가기 4개(SOS, Refused?, Food card, My trip)가 나오는지
- [ ] SOS에서 "Where am I?"를 누르면 크롬이 위치 허용을 묻고, 노란 칸에 글자 2개 + 숫자 8개가 나오는지. **119·112에 실제로 전화하거나 문자를 보내지 마세요.** "Text 119"는 문자 앱이 열리고 한국어 문구가 채워지는 것까지만 보고 지우기
- [ ] 비행기 모드(위치는 켠 채)에서 SOS의 "Where am I?"가 되는지(야외에서 1분까지 걸릴 수 있음)
- [ ] My trip에서 종 모양을 누르면 달력 앱이 열려 일정으로 저장되는지

**플레이에서 받은 앱일 때 (비공개 테스트 이후)**
- [ ] 맨 위 상태 표시줄이 파란색이고, 주소창이 없는지 (지문을 사이트에 넣은 뒤)
- [ ] 메신저에서 easymodekorea.com 링크를 누르면 앱으로 열리는지
- [ ] 첫 화면에서 뒤로 가기를 누르면 앱이 닫히는지
- [ ] 엄지로 아래 메뉴 4개와 홈의 주제 버튼을 누르기 편한지

알고 있는 한계: 설치 직후 **한 번도 인터넷에 연결하지 않고** 처음 열면 내용이 뜨지 않습니다(폰에 저장된 것이 아직 없기 때문). 한 번 열고 나면 그 뒤로는 오프라인에서도 열립니다.
