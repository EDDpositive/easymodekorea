# 일본 면세 환급 도우미: 4주 시험

- 화면: `ko/japan-tax-refund.html` 한 장(한국어). 사이트 메뉴와 앱에는 안 나오고 사이트맵에만 있음. 오프라인 저장도 따로(`ko/sw.js`).
- 만드는 곳: `src/jp_refund.py` 한 파일. 규칙·공항·문답·출처가 모두 여기 있음.
- 안 하는 것: 환급 업체·카드·수수료 비교, 제휴 링크, 업체 이름 쓰기. `tools/check_site.py`가 이름을 찾으면 실패함.
- 입력한 것은 폰에만 저장. 세는 것은 방문 수와 버튼(`jpr/result`, `port`, `add`, `step`, `card`, `map`, `vjw`, `kcs`, `ics`, `share`).

## 매주 5분
1. `python tools/jp_refund_check.py`: 공항 41곳의 층과 폰 절차를 일본 세관 목록과 비교.
2. 일본 국세청 [새 소식](https://www.nta.go.jp/publication/pamph/shohi/menzei/201805/format/002.htm)과 관광청 [여행자 안내](https://www.mlit.go.jp/kankocho/tax-free/page01_000001_00021.html)에 바뀐 것이 있는지 보기.
3. 바뀌었으면 고치고 `CHK` 날짜를 그날로 바꾸기. 확인만 했으면 날짜만 바꾸기.
4. 2027년 4월 식품 세율 인하 법안이 통과되면 `FOOD_CUT` 계산을 실제 세율로 바꾸기.

## 정하는 날(공개일부터)
| 날 | 보는 것 | 정하는 것 |
|---|---|---|
| 2주 뒤 | 검색에 떴는지 | 안 떴으면 제목·말을 고치고 2주 더 |
| 4주 뒤 | 한 주 방문, 방문 100명당 버튼 | 주 30명 이상이고 버튼 20번 이상이면 영어·번체로 넓힘. 주 10명 미만이면 접음. 사이면 2주 더 보고 끝 |

## 확인 안 됨
- 일본어 카드 8장의 원어민 확인. 실제 공항에서 와이파이·폰 절차를 써 본 확인.
- 환급 업체마다 다른 현금 창구의 위치(보안 검색 앞인지 뒤인지). 그래서 화면에 적지 않음.
