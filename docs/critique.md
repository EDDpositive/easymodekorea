# easymodekorea.com 혹평 리뷰 (1차, 2026-11-20)

검토 관점: 한국에 처음 오는 외국인 여행자 / Google 검색 / 상위 경쟁 가이드(Trip.com, Wise, Creatrip, 10Mag, VisitKorea 등 "Naver Map English", "Korea taxi app foreigner", "T-money card", "K-ETA" 상위 결과).
방법: 라이브 사이트를 내장 브라우저로 데스크톱·모바일(375px) 폭에서 확인, `src/build.py`·`src/data.py`·`src/vi.py`·`hosts.html` 코드 확인, 핵심 사실 5건을 공식 발표·언론 보도와 대조.

## 한 줄 결론

빠르고 깔끔하며 "내 상황별 답"이라는 콘셉트는 경쟁 사이트에 없는 강점입니다. 하지만 **가이드 본문이 너무 얇아서**(택시 가이드 본문 약 88단어, 페이지 전체 약 237단어) 검색 1페이지에 오른 1,500~3,000단어짜리 스크린샷 가이드와 경쟁이 안 됩니다. 사실 오류도 2건 있습니다(1339 안내, 전자도착카드를 "보도에 따르면"으로 흐리게 쓴 부분). 지금 상태는 "잘 만든 요약 카드"이지 "검색 1위 가이드"가 아닙니다.

- **차별점**: 사실 줄마다 확인일 표시, 한국어 표시·복사 카드, 오프라인(서비스 워커가 읽는 언어의 페이지를 약 32개 미리 저장), CSS를 공용 파일 1개로 빼서 가이드 HTML이 44KB에서 27KB로 줄어듦.
- **유지**: SEO 메타·hreflang·Article/Breadcrumb/FAQPage 스키마(FAQ 스키마는 접힌 FAQ와 같은 내용), 5개 언어, 본문 맥락 링크, 관련 가이드. 접힌 섹션 주소(`#fq-taxi` 등)로 들어오면 자동으로 펼쳐짐.
